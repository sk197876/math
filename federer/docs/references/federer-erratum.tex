\noindent\textbf{Transcription information (editorial).}
This is a LaTeX transcription of the cover and twelve numbered correction
pages of Herbert Federer's \textit{Geometric Measure Theory: List of
corrections}, May 1987 (citation key \texttt{Federer1987Erratum} in the
project bibliography, \texttt{docs/bibliography.md}). The date above is read from the cover, not from the
incorrect OCR reading ``1937''. The source scan was consulted visually.
Page and line numbers in the tables refer to the printed book; section
headings below preserve the erratum's own page numbers. Fragments are left
as fragments: they specify replacements in the book, not standalone claims.
Typeface instructions, insertion/deletion instructions, are retained; underlining used merely for emphasis in the scan is not
reproduced consistently. Script letters and restriction signs are rendered with modern
LaTeX glyphs. Large replacements are set outside the tables for readability.
This file transcribes Federer's corrections; it does not incorporate the
additional corrections or counterexamples developed in this repository.
